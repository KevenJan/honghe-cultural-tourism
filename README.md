# honghe-cultural-tourism
红河民族文化融合小程序

产品名：**红河同路** —— 各族同路走，好物一路带

## 汇报讲解

- [产品规划说明报告](docs/08-产品规划说明报告.md)：给甲方和领导看的文字版。按模块讲清游客端 M1–M8、店员端、合作社端、运营后台 B1–B8 的链路、规则和数据，六个闭环，游客每一步的心理，运营分工、分期验收、需协调事项和风险
- [汇报讲解网页](presentation/README.md)：42 页 16:9 演示稿，和 08 号报告一一对应，每页附讲稿（N 键 / `?mode=script`）。双击 `presentation/index.html` 即可打开，不依赖外部资源，可整体部署到静态服务器。小程序和后台界面用 HTML 重绘，「同心石榴」可现场点击演示。

## 文档

- [内容产品文档](docs/01-内容产品文档.md)：定位、用户、信息架构、四站内容与题目草稿、积分称号礼品规则、一路好物、审定与 AI 规则、分期、指标与风险
- [产品 UI 与交互设计](docs/02-UI交互设计.md)：视觉系统、关键路径、首页 / 现场页 / 答题 / 结果 / 称号与礼品 / 商品列表 / 商品详情 / 店员核销的线框与状态、评审清单
- [地方政策对照审查](docs/03-政策对照审查.md)：对照《民族团结进步促进法》、红河县十五五规划、2025 年度县情等，列出必须改与建议补的内容及出处
- [参考借鉴与 v2 优化方案](docs/04-参考借鉴与v2优化方案.md)：8 张参考图逐张取舍、v1.1 的 16 处优化、v2 信息架构（五标签 + 同心石榴 + 问驮驮）、关键页面变化、视觉调整、设计图与待修正文字
- [设计 PROMPT v3](docs/05-设计PROMPT.md)：整体产品 PROMPT、风格总纲与 19 屏逐字文案 PROMPT、独立素材 PROMPT、色键底出图与导出规范、出图后校对清单
- [到达打卡与同心石榴互动设计](docs/06-打卡与民族融合互动设计.md)：独立的打卡流程与异常状态；石榴模型（四瓣 = 四站，五颗籽 = 世居五族）、点籽放大交互、四站 × 五籽内容矩阵、非遗卡、一句红河话
- [缺陷修复与实现方案](docs/07-缺陷修复与实现方案.md)：28 处修复（表述与合规、微信小程序实现难点、设计缺陷），以及上线前需甲方准备的事项

> 研学模块界面名为「同心石榴」，副标题「交往交流交融 · 研学」；「民族融合」只作内部主题词。
