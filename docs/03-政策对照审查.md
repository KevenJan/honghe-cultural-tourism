## 2. 必须改（7 项）

### 2.1 人口比例已有新口径

| | v1.0 写法 | 2025 年度县情 |
|---|---|---|
| 少数民族占比 | 约 96.74% | **96.89%** |
| 哈尼族占比 | 约 80.89% | **81.4%（29.39 万人）** |
| 补充 | — | 户籍总人口 36.09 万人；世居汉、哈尼、彝、傣、瑶 5 个民族；全国最大的哈尼族聚居县 |

**处理**：入口站内容卡和第 2 题改用 2025 年度县情口径，并在卡片上注明「据红河县县情概况（2025 年度）」。数据卡做成运营后台可配的字段，每年县情更新时只改一处。
**提醒**：项目说明原本要求“人口以说明为准”。这次是按最新官方县情更新的；如果县文旅坚持用原口径，回退只需改这一个字段。

### 2.2 审定主体要加上民族工作部门和文物部门

民族团结进步促进法第三十条：「县级以上人民政府**民族工作部门**应当会同**文化和旅游、文物**等部门，依托中华民族共同体理论和史料，规范展陈展示、讲解等内容。」

**处理**：审定流程从「文化馆审定 → 文旅确认」改为：

```
运营起草 → 县文化馆 / 传承人（事实与非遗） → 县民族宗教事务局（民族表述） → 县文旅局（上线）
                                  ↑ 马帮古城内容另加文物主管部门（全国重点文物保护单位）
```

内容卡底部的审定行相应改为「经红河县民宗局、文旅局、文化馆审定」。

### 2.3 融合的表述改用法定和规划用语，并补上「共同性」这一层

- 法律序言与第六条：「以增进共同性为方向」「坚持增进共同性、尊重和包容差异性」。
- 第十三条：「各民族优秀传统文化都是中华文化的组成部分。」
- 国家民委解读：「不能把文化差异简单罗列、孤立展示，更不能以猎奇化、标签化方式制造隔膜、固化差异」；讲解要回答「彼此怎样联系」「何以成为中华文化的一部分」。
- 县十五五与县党代会：「促进各民族交往交流交融」「推动各民族全方位嵌入」「以铸牢中华民族共同体意识为主线」。

v1.0 的问题：

1. 产品原则「融合不是消失：各自保有、彼此往来」只讲了差异性，没有讲共同性，方向上偏了半步。
2. 入口站第一张卡「一个县，五个民族」容易被读成罗列。
3. 四站讲了“彼此往来”，但没有一句落到“这些都是中华文化的一部分”。

**处理**：

- 原则改为「**增进共同性，尊重差异性**：讲各族共同生活、共同创造，也尊重各自的语言、服饰和节庆」。
- 对外文案统一用「交往交流交融」。「民族融合」只作为内部主题词，不单独出现在界面上；需要时用法律第二十三条的「团结融合」「和谐融居」。
- 入口站第一张卡改为「同住一个县，同走一条路」，先讲共同生活，再给数字。
- 每站内容的最后一句落到共同性，例如梯田站：「这片梯田是各族共同守护的世界文化遗产，也是中华农耕文明的一部分。」
- 品牌名「红河同路」、副标「各族同路走，好物一路带」与上述导向一致，不用改。

### 2.4 语言文字：族语内容必须以普通话为主

第十五条：公共场合同时使用国家通用语言文字和少数民族语言文字时，「应当在位置、顺序等方面突出国家通用语言文字」。

**处理**：日后经审定加入族语（例如乐作的哈尼语释义、授权的多声部录音）时，界面上普通话文字在前、字号更大，族语作为补充；音频先放普通话讲解。英文、越南语等外语同样以中文为主版本。

### 2.5 网络内容管理：评价、留言、AI 都要有处置机制

第三十一条：网络运营者发现含有民族歧视等破坏民族团结进步内容的信息，应立即停止传输、消除、保存记录并报告。

**处理**：商品评价、反馈留言、日后的 AI 讲解员，全部先审后发或机审加人工复核；后台保留处置记录。AI 讲解员遇到民族、宗教相关提问，只复述审定内容，没有就答“不知道”（v1.0 已有，保留）。

### 2.6 森林公园：森林防火和滑坡提示必须进页面

- 林草局：马帮侨乡森林公园是防火重点部位，高火险期防火区内**全面禁止一切野外用火**。
- 林草局提案答复：森林公园下方冲沟曾发生山体滑塌，正在治理。

**处理**：

- 森林公园站到达页、营地相关商品页常驻防火提示：「高火险期园区内禁止一切野外用火，房车营地请使用指定设施。」
- 「营地常备」清单不上架明火类商品（炭、户外烧烤燃料等）。
- 雨季和治理期间，桩位与步行内容避开滑坡点，桩位说明写清“请走游客步道”。

### 2.7 马帮古城：文保身份要写对，望江亭不能当现场点

- 2025 年度县情：马帮古城是「中西式、传统清式民居建筑群」，建筑总面积 2 万余平方米，有「江外建筑大观园」之称；2003 年列入省级第六批文物保护单位，2013 年列入国家级文物保护单位，2025 年 1 月认定为国家 4A 级旅游景区。县文旅局提案答复写的是「东门楼及迤萨民居 18 幢」为国家级文物保护单位。
- 同一份答复：**望江亭项目已动工**，即 2025 年中尚未建成。

**处理**：

- 古城站补一张文物卡片，并加文物礼仪：不刻画、不攀爬、不触摸彩绘与木雕、院落住户未同意不入内。
- 望江亭卡片改为讲「送别和等候」的故事，不引导游客去现场；建成开放后，由运营在后台把它打开为可到达的点位。
- 「云南省第二大侨乡」只出现在部分报道里，县情写的是「云南省著名的侨乡之一」，界面统一用县情的说法。

## 4. 无需修改、与政策一致的部分

| v1.0 设计 | 对应政策 |
|---|---|
| 不做四个民族馆、不做五族图鉴首页 | 反对差异“简单罗列、孤立展示” |
| 不做整套民族服装变装，不排民族高低，称号与民族无关 | 第五条各民族一律平等；反对猎奇化、标签化 |
| 族语、祭祀、族源、迁徙必须审定后才出现；AI 不生成 | 第三十条规范讲解内容；史料核验 |
| 寨神林只讲敬重；拍人、拍院落、拍宴席先征得同意 | 尊重和包容差异性；落实宗教相关规范 |
| 农户、合作社、手艺人有名有姓，订单写清来源 | 第三十六条利益共享；州长要求健全联农带农机制 |
| 文创以本地手艺人为主 | 第三十条开发弘扬中华文化的文化创意产品 |
| 侨乡讲“出门的人和等的人” | 第二十一条加强同海外侨胞的联系交流 |
| 支线沿官方环线迤萨—甲寅—宝华—乐育 | 十五五「侨农文旅融合发展带」 |
| 安全优先：匝道不设点、只取一次定位 | 统筹发展和安全 |
