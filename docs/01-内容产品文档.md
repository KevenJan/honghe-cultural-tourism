## 1. 产品名称与定位

### 1.1 名称：红河同路

| 层级 | 文案 | 作用 |
|---|---|---|
| 主名 | **红河同路** | 「同路」既是游客自己在走的这条长廊，也是各族群众在同一片土地上来往、同走一条路的日常 |
| 副标 | **各族同路走，好物一路带** | 前半句讲民族融合，后半句讲红河物产，一句话把两件事接起来 |
| 积分名 | **同路分** | 只用来证明「看懂了」，不叫金币、不叫豆子，避免让人联想到钱 |
| 商城名 | **一路好物** | 东西按「在哪一站遇到的」来组织，不做通用商城 |

为什么不用别的名字：

- 不用「X族风情」「民族大观园」：会把产品引向「民族馆、图鉴」。
- 不用「长街宴」「多声部」这类单一民族的文化符号当品牌：主题是融合，品牌应当谁都站得进去。
- 不用「打卡」「闯关」：四站不是关卡，打卡只是记一笔。

### 1.2 产品要同时做到的四件事

1. **把人留在现场**：到了地标才能解锁这一站，站着三分钟能看完、能听完。
2. **讲清融合**：讲日常生活，讲同一条路、同一沟水、同一条街、同一片梯田，不讲口号。
3. **让本地货被买走**：每一站都自然地连到这一站的物产，农户、合作社、手艺人有名有姓。
4. **可被审定、可被核销**：民俗内容可追溯到审定记录，礼品发放可追溯到店员和柜台。

### 1.3 设计原则（评审时可逐条对照）

| 原则 | 具体规定 |
|---|---|
| 走一站也有收获 | 完成任意一站即可领第一档礼；四站全满是荣誉，不是门槛 |
| 可顺可逆 | 四站没有编号、没有先后锁，任意一站都可以先走 |
| 先安全，再打卡 | 定位只在游客主动点「我已停好，打卡」时取一次；不做后台定位、不做山路导航；匝道、主路不设打卡点 |
| 增进共同性，尊重差异性 | 讲各族共同生活、共同创造，每站最后落到「这也是中华文化的一部分」；同时尊重各自的语言、服饰和节庆。对外统一用「交往交流交融」，「民族融合」只作内部主题词；不出现「同化」「融为一族」，也不把差异罗列成图鉴 |
| 不排高低 | 称号按「到过几站、看懂多少」累加，与民族无关；形象只加授权纹样配饰，不换整套民族服装 |
| 敬重优先于好玩 | 寨神林、祭祀不做成游戏、不做答题素材里的“趣味题” |
| 没审定就不说 | 族语歌词、祭祀流程、族源、迁徙，审定前一律不出现；AI 不生成这几类内容 |
| 普通话为主 | 审定后加入族语内容时，普通话文字在前、字号更大，族语作补充；音频先放普通话讲解 |
| 物产不是广告 | 入口只“认识”物产、加心愿单，不在停车场催付款；首页不放与现场无关的广告位 |

## 2. 用户与场景

| 用户 | 典型情境 | 最在意的 | 产品给他的 |
|---|---|---|---|
| **自驾 / 周末游客**（一期主用户） | 停留半天到两天，大多认真走一到两站 | 别耽误行程、好拍、带点东西回去 | 一站三分钟的内容、一份第一站就能拿到的礼、寄回家的本地货 |
| **旅居 / 房车客**（森林公园） | 停留更久，营地有冰箱和储物空间 | 日常吃的、耐放的山货，能重复买 | 「营地常备」清单、到营地自提、一键再买一次 |
| **农户、合作社、手艺人** | 在村里、在作坊里，不一定常看手机 | 订单说得清：谁买的、在哪看到的、要什么时候发 | 带来源的订单通知、自己的「来源档案」页 |
| **店员 / 柜台人员** | 在访客中心、文创店、观景台服务点 | 扫一下就知道能不能发、发哪一档，别出错 | 店员模式：扫码、看档位、选礼品、确认发放 |
| **县民宗局、县文旅局、县文化馆、文物主管部门** | 依《民族团结进步促进法》第三十条规范讲解内容；文化馆对民俗表述有审定权 | 不出错、可追溯、能下线 | 内容审定流程、每条内容的审定记录、一键下线 |
| **研学与团队**（预留） | 州内学校研学、央企职工疗休养与党建研学团 | 统一组织、看得到完成情况 | 团队码、带队人查看进度、研学证书 |

### 2.1 一位游客的完整路径（主线故事）

> 周六上午，杭州来的一家三口自驾进红河县。

1. **到达**：从迤萨高速出口下来，跟着路牌进入出口后的访客停车场，停稳车。副驾的妈妈打开「红河同路」，点「我已停好，打卡」。小程序取一次定位，确认在访客点范围内。
2. **看内容**：「同住一个县，同走一条路」——四张卡片、一段 2 分 40 秒的音频，讲汉、哈尼、彝、傣、瑶各族怎样走同一条路、一起过日子。孩子在车边听完。
3. **答题**：三道题。第二题答错了，页面先告诉他正确答案和原因，再给 3 分，照样往下答。最后得 23 分。
4. **记下这一站**：小程序盖上「迤萨路口」的徽记，称号变成「红河来客」，提示：「你已经可以领第一档礼了，访客中心柜台就能领；也可以再走一站，领更好的一档（每人每年只领一次）。」
5. **认识物产**：页面底部是「这一路你会遇到」：撒玛坝的梯田红米、古城的竹编和尼苏刺绣。妈妈把红米加进心愿单——这里不收钱。
6. **下午到撒玛坝**：在观景台再打一次卡，听开秧门和长街宴，答对三道题（30 分）。称号升级为「红河同路人」，达到第二档礼。
7. **领礼**：观景台服务点，妈妈出示「领礼码」，店员扫码，系统显示「第二档，可发放」，店员选一份梯田红米小礼盒，确认。妈妈手机上的礼品页立刻变成「已领取」。
8. **买走本地货**：心愿单里的红米，详情页写着哪个镇、哪个合作社、哪一季，选择「寄回家」。下单后，合作社收到一条订单：「买家在撒玛坝观景台看完梯田一站后下单」。

这条路径就是一期要跑通的主线，所有页面都为它服务。

## 4. 四个实景站点

### 4.1 统一结构：每站五步

```
① 到达确认 → ② 看 / 听这一站 → ③ 互动答题 → ④ 记下这一站 → ⑤ 这一站的物产
```

| 步骤 | 规则 |
|---|---|
| ① 到达确认 | 先勾选「我已停稳 / 我是乘客」，再点打卡，此时取一次定位；落在可打卡范围内即算到达。定位弱时可扫现场桩位上的二维码（桩码）。如果单次定位显示还在移动（车速明显大于步行），提示「请停稳后再打卡」，不打卡 |
| ② 看 / 听 | 3–4 张卡片，每张正文不超过 120 字；一段总长不超过 3 分钟的音频，可离线播放；有文字稿，听不清也能看 |
| ③ 答题 | 每站 3 题。答对 10 分；答错先看正确讲解，再得 3 分，可以继续。不重答刷分，可以随时回看讲解 |
| ④ 记下这一站 | 看完内容即生成到访记录（站点徽记点亮）；答题分数累计进同路分；同步更新称号与礼品档位 |
| ⑤ 物产 | 这一站相关的 2–4 件本地货；入口站只能加心愿单，其余站可直接购买 |

补充规则：

- 到达后 6 小时内可以回到车里或酒店把内容看完、把题答完，不必重新定位。
- 离线时打卡、看内容、答题都能完成，记录标为「待同步」，联网后自动上传；**领礼核销必须联网**。
- 同一站同一自然年只计一次分；再次到达可以重看、重听，但不重复得分。

### 4.2 站点一览

| 站点（App 内名称） | 打卡位置（人实际站着的地方） | 这一站讲什么 | 物产角色 |
|---|---|---|---|
| **迤萨路口** | 迤萨高速出口**后**的访客停车场 / 访客点【待定：具体桩位】 | 同住一个县，同走一条路 | 认识物产、加心愿单 |
| **马帮侨乡森林公园** | 森林公园游客中心或营地服务点【待定】 | 大家共用一沟水：森林—村寨—梯田—水系「四素同构」 | 耐储山货、营地常备、复购 |
| **马帮古城** | 迤萨镇东门街（国家 4A 景区，国家级文物保护单位）【待定：街口桩位】 | 出门的人和等的人：马帮、侨乡、中西合璧的房子、望江亭的故事 | 文创主场：竹编、傣族制陶、彝族（尼苏）刺绣（审定后）、授权纹样文创 |
| **撒玛坝梯田** | 宝华镇撒玛坝万亩梯田观景台，或步行可达的村寨口（如龙玛村旅居示范点）【待定】 | 同一片梯田，同一张长桌：农耕、开秧门、仰阿娜、长街宴、乐作、哈尼多声部 | 农特产主场 |

> 名称写法统一：**迤萨**（不写「迤撒」）；**马帮古城**（不写「马棒」）。
>
> 只走两站的游客，首页软推荐「马帮古城 + 撒玛坝梯田」。这两处是县里的两个国家 4A 景区，县里的说法是「山上生态、城中人文」。推荐不改变四站可顺可逆、不上锁的规则。
>
> **每站最后一句落到共同性**：讲完这一站的具体生活，用一句话说明它是各族共同创造、共同守护的，也是中华文化的一部分。这句话同样要审定。

### 4.3 迤萨路口 · 同住一个县，同走一条路

**桩位**：迤萨高速出口后的安全停车场或访客点。匝道、主路、应急车道一律不设桩位，也不出现“拍照点”提示。

**到达提示文案**

> 欢迎来到红河县。请先把车停进出口后的访客停车场，停稳了再打开这一站。

**内容卡（草稿）**【待审】

1. **同住一个县，同走一条路**
   山里的人出来赶街、卖货，坝子里的人进山收货、走亲戚。路是大家一起走的，货是大家一起换的。【待审：具体举例需文化馆提供】
2. **一个县里的各族人家**
   红河县世居汉、哈尼、彝、傣、瑶 5 个民族，户籍总人口 36.09 万人。少数民族人口占总人口的 96.89%，其中哈尼族占 81.4%，红河县是全国最大的哈尼族聚居县。
   <sub>据红河县县情概况（2025 年度）</sub>
3. **这一路你会遇到**
   往前走，你会经过共用一沟水的森林和村寨，走进马帮出发、侨眷等候的古城，站到层层梯田的观景台上。每一站都是各族一起过日子、一起守护的地方，也都是中华文化的一部分。
4. **先认识，再带走**
   这一站先认识这一路的物产。喜欢的放进心愿单，到了产地再买，或者回家前寄走。

**音频**：约 2 分 30 秒，普通话旁白，背景只用环境声，不用族语歌曲。

**题目（草稿）**

| # | 题干 | 选项 | 正确项 | 答错后的讲解 |
|---|---|---|---|---|
| 1 | 在高速路口打卡，应该在哪里停车？ | A 匝道边 / B 出口后的访客停车场 / C 主路应急车道 | B | 匝道和主路车速快，停车很危险。红河同路的打卡点都设在出口后的访客停车场。 |
| 2 | 红河县少数民族人口约占总人口的多少？ | A 约 50% / B 81.4% / C 96.89% | C | 据 2025 年度县情，少数民族人口占总人口的 96.89%，其中哈尼族占 81.4%。两个数字说的是不同的事。 |
| 3 | 这一站讲的“交往交流交融”更接近哪种说法？ | A 各族各过各的，互不往来 / B 各族同走一条路、一起过日子，彼此尊重 / C 只有一个民族住在这里 | B | 各族在同一片土地上来往、一起生活、一起创造，共同的东西越来越多；各自的语言、服饰、节庆也都受到尊重。 |

> 人口数字放在运营后台的「县情数据」字段里，每年县情更新时只改这一处，内容卡和题目同步更新。

### 4.4 马帮侨乡森林公园 · 大家共用一沟水

**桩位**：森林公园游客中心或营地服务点。旅居、房车客常驻在这里。桩位和步行内容避开园区下方曾发生滑塌的冲沟，桩位说明写「请走游客步道」。

**内容结构**：森林—村寨—梯田—水系，一条线讲到底。这一结构的官方说法是「四素同构」，卡片标题可以直接用。

**防火提示（常驻，不属于答题内容）**

> 这里是森林防火重点区域。高火险期园区内禁止一切野外用火，房车营地请使用指定设施，烟头请带走。

防火提示出现在到达页顶部和所有营地自提商品页上；运营可在高火险期把它升级为醒目的横幅。

**内容卡（草稿）**【待审】

1. **水从森林里来**
   山上的森林留住雨水，水顺着沟渠流过村寨，流进层层梯田，再汇入河谷。住在山上、山腰、河谷的各族人家，用的是同一个水系。
2. **一沟水，大家一起管**
   水要大家一起护、一起分，才能从山顶流到坝子。【待审：用水、护林的具体约定由文化馆提供，不自行编写】
3. **寨神林：请保持敬重**
   村寨旁的寨神林是当地人敬重的地方。经过时请放轻脚步、不攀折、不喧哗；未经允许不进入、不拍摄。【待审：具体礼仪表述】
4. **在这里住下来的人**
   森林公园已在接待旅居和房车客人。住下来的日子里，这里的山货可以一次次买、一次次吃。护林防火也是住在这里的每个人的事。

> 寨神林只出现在“敬重”这一张卡里：不做答题的趣味素材，不做 AR，不做打卡点，不讲祭祀流程。

**题目（草稿）**

| # | 题干 | 正确项 | 答错后的讲解 |
|---|---|---|---|
| 1 | 这一站讲的水，按什么顺序流过？ | 森林—村寨—梯田—水系 | 森林留住水，村寨用水，梯田存水，最后汇成水系。各族人家用的是同一条水路。 |
| 2 | 经过寨神林，比较合适的做法是？ | 放轻脚步，不攀折，未经允许不进入、不拍摄 | 寨神林是当地人敬重的地方，我们作为客人，先把敬重放在前面。 |

### 4.5 马帮古城 · 出门的人和等的人

**桩位**：迤萨镇东门街，马帮古城（国家 4A 景区）街口。

**文物身份（审定时请文物主管部门确认）**：马帮古城是中西式、传统清式民居建筑群，建筑总面积 2 万余平方米，有「江外建筑大观园」之称；2003 年列入省级第六批文物保护单位，2013 年列入国家级文物保护单位（县文旅局资料写作「红河县东门楼及迤萨民居 18 幢」），2025 年 1 月认定为国家 4A 级旅游景区。

**内容卡（草稿）**【待审】

1. **马帮从这里出发**
   过去，马帮从这里出发，把山里的货运出去，也把外面的东西带回来。各族的货、各族的人，在这条路上来来往往。
2. **侨乡**
   县情记载，红河县在外华侨 1 万余人，分布于 18 个国家和地区，是云南省著名的侨乡之一。他们走出去的路线各不相同，但都记得家乡。【待审：具体路线不在一期展示】
3. **中西合璧的房子：江外建筑大观园**
   走出去的人把见过的样式带回家乡，于是这里有了中式院落和西式门窗拼在一起的房子。这片建筑群是国家级文物保护单位，请只看不刻、不攀爬、不触摸木雕和彩绘；院子里有人住，未经同意不进门。【待审：具体建筑名称与描述】
4. **望江亭：送别和等候**
   望江亭讲的是两种心情：送人出门，和等人回来。马帮出门、侨胞远行，家里人就在高处望着江。你也可以想想自己最近一次送别和等候。

> **望江亭在县文旅局 2025 年 7 月的答复中仍是「已动工」的在建项目。**一期只讲它的故事，不把它当作现场点、不引导游客前往；建成开放后再由运营在后台开放为可到达点位。
>
> **晚上再来**：县里以马帮古城为夜间经济核心（「马帮古城·夜红河」、星光夜市）。古城站结果页加一张「晚上再来」卡片，只在「现在发生」页有真实活动时显示活动信息，例如国庆期间的小黄牛长街宴。

**题目（草稿）**

| # | 题干 | 正确项 | 答错后的讲解 |
|---|---|---|---|
| 1 | 县情记载，红河县在外华侨分布于多少个国家和地区？ | 18 个 | 在外华侨 1 万余人，分布于 18 个国家和地区，各支走出去的路线并不相同。 |
| 2 | 望江亭讲的是哪两种心情？ | 送别和等候 | 送人出门、等人回来，是马帮和侨乡人家共同的日常。 |
| 3 | 在马帮古城的老房子前，比较合适的做法是？ | 只看不刻、不攀爬，院里有人住时先问再进 | 这片建筑群是国家级文物保护单位，也是很多人家的家。看得仔细，也看得礼貌。 |

**物产**：这条街是文创主场——竹编、傣族传统制陶、彝族（尼苏）刺绣（省级非遗，需文化馆确认后列入）、县文旅局已开发的马帮与刺绣文创、使用授权纹样的文创小件。街上的合作门店可以当场自提。

### 4.6 撒玛坝梯田 · 同一片梯田，同一张长桌

**桩位**：宝华镇撒玛坝万亩梯田（国家 4A）观景台，或步行可到的村寨口。宝华镇龙玛村是县里的民族文化体验旅居示范点（「村长有请」活动所在地），可优先评估作为村寨桩位【待定】。
**高速口只是门户**：如果一期桩位只能设在撒玛坝高速路口访客点，打卡页文案改写为人真正站着的地方：

> 你现在在撒玛坝高速路口访客点。梯田在前方宝华镇，观景台和村寨里能看到这一站讲的全部内容。

（两版文案由站点的「桩位类型」切换，运营后台选择，不需要改版。）

**关键数字（只用这一套口径）**

| 项目 | 写法 |
|---|---|
| 连片梯田面积 | 约 1.6 万余亩 |
| 级数 | 4300 多级 |
| 海拔 | 大约 600 米到 1800 米 |
| 冬春灌水季 | 大约 11 月到次年 4 月 |
| 身份（县情写法） | 世界文化遗产、全球重要农业文化遗产中最为著名的一片；2018 年被授予中国（连片）面积最大的哈尼梯田；2021 年 4 月认定为国家 4A 级旅游景区 |

> 「核心景区」面积是另一个口径，本产品**不使用**，也不和上面的数字放在同一句话里。县情里「全县梯田面积 26 万余亩」也是另一个口径，只能用于全县介绍，不能写成撒玛坝的面积。

**内容卡（草稿）**【待审】

1. **从 600 米到 1800 米**
   眼前这片连片梯田约 1.6 万余亩、4300 多级，从海拔大约 600 米一路铺到 1800 米。每年大约 11 月到次年 4 月是冬春灌水季，水面会映出天光。森林、村寨、梯田、水系「四素同构」，是各族世世代代一起守护的世界文化遗产，也是中华农耕文明的一部分。
2. **开秧门与仰阿娜**
   开秧门是一年插秧开始的日子；仰阿娜即姑娘节。县里每年举办「开秧门·仰阿娜」系列文化活动，「齐聚梯田边 欢庆开秧门」线路入选文旅部「岁时节令 自在乡村」精品线路。【待审：节庆是什么、游客如何有礼貌地参与——只写说明，不写仪式流程】
3. **长街宴：一张很长的桌子**
   长街宴把很多家的饭菜摆成一条长街，客人也会被请上桌。可以饮酒，也可以以茶代酒，不必勉强。拍人、拍院子、拍宴席之前，先问一声。
4. **乐作舞和多声部：是两件事**
   乐作舞重在舞，在哈尼族、彝族群众中世代相传，「乐作」在哈尼语中是「大家一起来玩跳」的意思，被邀请时再加入。哈尼多声部重在领唱与应和，一人起头，众人相和。两者都是国家级非物质文化遗产。【待审：「乐作」释义已见于县政府公开报道，仍需文化馆确认后使用】

**音频**：旁白 + 梯田环境声。**不使用未授权的多声部录音和族语歌曲**；获得传承人授权并经文化馆审定后，二期再加入。

**题目（草稿）**

| 1 | 撒玛坝梯田冬春灌水季大约是什么时候？ | 11 月到次年 4 月 | 这段时间梯田蓄满水，是看水面倒影的季节。 |
| 2 | 在长街宴上不喝酒，可以吗？ | 可以，以茶代酒 | 长街宴可以饮酒，也可以以茶代酒，主人看重的是你来了。 |

## 6. 同路分、称号、形象、礼品

### 6.1 三样东西各证明什么

| 东西 | 证明什么 | 怎么来 |
|---|---|---|
| 站点徽记（打卡） | 到过、并看完了 | 到达确认 + 看完内容 |
| 同路分 | 看懂了 | 答题：对 10 分，错 3 分（先看讲解） |
| 称号 / 形象配饰 | 荣誉 | 按站数与分数累加 |
| 官方礼品 | 一年一次的感谢 | 柜台由店员扫码发放 |

每站满分 30 分，四站满分 120 分。**同路分不能提现，不能抵现金，不能在商城里抵扣**——商城结算页不出现任何积分字样。

### 6.2 称号（按到过的站数，和民族无关）

| 称号 | 条件 | 形象变化 |
|---|---|---|
| 红河来客 | 完成任意 1 站 | 形象出现第一件配饰 |
| 红河同路人 | 完成任意 2 站 | 两件配饰 |
| 红河熟客 | 完成任意 3 站 | 三件配饰 |
| **长廊同心人**（荣誉） | 四站全部完成 | 四件配饰 + 荣誉边框 |

站点徽记有两种状态：**到过**（线描）和**答懂**（该站 ≥ 20 分，填色）。“答懂”只是让徽记更好看，不影响称号。

### 6.3 形象与配饰

- 形象是一个**中性的旅人**，不带民族服装，谁都可以是他。
- 每一站对应一件配饰，用的是**地方的东西**，不是某一个民族的整套服饰：
  - 迤萨路口：路牌纹挎包扣
  - 森林公园：水波纹挂坠
  - 马帮古城：马铃铛
  - 撒玛坝：梯田等高线围巾
- 若使用奕车服饰等民族纹样，**必须取得授权**，只用于配饰的边纹，不做整套变装。【待定：纹样授权清单】
- 四件配饰并列展示，没有“高级配饰”。

### 6.4 礼品档位

| 档位 | 条件 | 礼品（示例，须为本地农特或文创）【待定：实物】 | 可领柜台 |
|---|---|---|---|
| 一档 · 一站礼 | 完成任意 1 站 | 梯田红米小袋 / 本地茶小样 / 竹编书签（三选一） | 四个站点柜台均可 |
| 二档 · 同路礼 | 完成 2 站，且同路分 ≥ 40 | 红米小礼盒 / 竹编杯垫 | 四个站点柜台均可 |
| 三档 · 熟客礼 | 完成 3 站，且同路分 ≥ 70 | 傣陶小器 / 山货组合 | 森林公园、马帮古城、撒玛坝 |
| 四档 · 同心礼 | 四站全完成，且同路分 ≥ 100 | 手艺人署名文创 + 梯田红米 | 马帮古城、撒玛坝 |

**规则**

1. **每证每年一次**：同一身份证件每个自然年只能领一次。
2. **取最高一档**：领取时系统按当时达到的最高档发放。领过之后，当年不能再“补差升档”。
3. 因此在领礼前，礼品页明确告诉游客：「现在领是第 X 档；再走一站可以领第 Y 档。今年只能领一次。」——让游客自己选择现在领还是再走一站。
4. **游客不能自己点亮领取**：游客端只出示领礼码，“已领取”状态只能由店员核销产生。
5. 第一档门槛刻意放低：一个只走了入口站的游客，在入口访客中心就能拿到一份小礼。
6. 领礼需完成一次实名（微信实名授权），柜台核对证件后四位。

## 7. 一路好物（农特产与文创）

### 7.1 组织方式：按站，而不是按“热卖”

| 分区 | 内容 | 购买方式 |
|---|---|---|
| 路口认识 | 这一路的代表物产总览 | 只能加心愿单 |
| 森林山货 | 耐储山货、营地常备（如生态茶叶、八角、林下菌干货） | 营地自提 / 寄回家 / 再买一次 |
| 古城文创 | 竹编、傣族制陶、彝族（尼苏）刺绣、马帮主题文创、授权纹样文创 | 东门街门店自提 / 寄回家 |
| 梯田农产 | 梯田红米、稻鱼鸭相关产品、时令农货（如百香果）、小黄牛制品 | 观景台服务点自提 / 寄回家 |

首页只出现“这一路你会遇到”的 3–4 件货，与用户已到或将到的站点相关；**没有开屏广告、没有与现场无关的推荐位**。

> 上面的品类来自县十五五规划、县党代会和县政府公开报道中点名的物产，具体商品以实际入驻为准。营地常备不上架炭、户外烧烤燃料等明火类商品。商品详情预留「区域品牌」标识位（如「红河九红」），取得授权后才显示。

### 7.2 每件商品必须有「来源档案」

| 字段 | 示例写法 |
|---|---|
| 谁做的 | XX 合作社 / 手艺人 XXX（经本人同意展示照片） |
| 在哪里 | 宝华镇 XX 村【以实际为准】 |
| 和这条长廊的关系 | “你在撒玛坝看到的梯田，产的就是这一袋米” |
| 什么时候产的 | 年份 / 批次 |
| 耐不耐放 | 常温可存 X 个月（用于旅居客判断） |
| 怎么拿到 | 寄回家 / 柜台自提 / 营地自提 |

### 7.3 给农户、合作社、手艺人的订单

订单通知（服务通知或合作社后台）写清楚：

> 新订单｜梯田红米 2 袋
> 买家在**撒玛坝观景台**看完「同一片梯田，同一张长桌」后下单
> 配送：寄回家（浙江杭州）｜请在 48 小时内发货

“下单场景”让生产者知道东西是怎么被卖出去的，也给县里留下“哪一站带动了哪类物产”的数据。

发货：县里是农村客货邮融合发展示范县，乡镇农户发货优先走客货邮线路；需要冷链的商品按县乡村冷链网络覆盖情况决定是否开放寄送。

### 7.4 旅居复购（v1.1 调整：一期先做「再买一次」和营地自提）

旅居是县十五五规划的十亿级产业之一，县里另编制了《加快推进旅居红河县三年行动计划（2025—2027 年）》，所以 v1.1 把旅居复购的一部分提前到一期。

- 一期：「再买一次」，从历史订单一键复购；森林公园营地自提。
- 二期：「营地常备」清单，一次勾选、定期送到营地服务点；覆盖范围从森林公园扩展到龙玛村等旅居示范点。
- 上线前对照《云南省旅居发展正负面清单 2.0 版》逐条核对。

## 8. 内容审定与 AI 规则

### 8.1 审定流程

依据：《民族团结进步促进法》第三十条，「县级以上人民政府民族工作部门应当会同文化和旅游、文物等部门……规范展陈展示、讲解等内容」。

```
运营起草 → 县文化馆 / 传承人（事实与非遗） → 县民族宗教事务局（民族表述） → 县文旅局（确认上线） → 上线
                ↑ 马帮古城相关内容另加文物主管部门                        ↓ 任一环节可退回；上线后随时可一键下线
```

- 每张内容卡底部显示一行小字：「内容经红河县民宗局、文旅局、文化馆审定 · 2026 年 X 月」。
- 审定时专项检查三件事：是否落到共同性；有没有罗列差异、猎奇化、标签化；族语是否以普通话为主。
- 题目的讲解必须引用已审定的内容卡，不得独立写新事实。
- 已下线内容关联的题目同步下线；已获得的分数保留。

### 8.2 AI 讲解员（二期）

- 只能复述已审定内容库中的文字，回答时附上来源卡片。
- 内容库里没有的，回答：「这个我还不知道。你可以问现场讲解员，或者在‘我的—反馈’里留言，我们请文化馆来答。」
- 不生成族源、祭祀、禁忌相关内容；遇到这几类问题直接走上面的“不知道”回答。

### 8.3 用户内容与网络信息管理

依据：《民族团结进步促进法》第三十一条，网络运营者发现含有民族歧视等破坏民族团结进步内容的信息，应立即停止传输、消除、保存记录并报告。

- 商品评价、反馈留言先机审，再人工复核后才公开；不开放游客之间的公开评论区。
- 发现违规内容立即下线，保留处置记录，按规定报告主管部门。
- AI 讲解员的提问和回答全部留档，供审定单位抽查。

## 12. 风险与对策

| 风险 | 对策 |
|---|---|
| 游客在匝道停车拍照 | 桩位只设在出口后的访客点；文案先讲停车；单次定位显示仍在行驶时不打卡；匝道处不出现任何拍照点 |
| 山区信号弱 | 离线包、桩码打卡、待同步；仅核销需联网 |
| 民俗表述出错 | 审定流程、审定记录展示、一键下线 |
| 融合被误读为同化，或反过来只讲差异 | 对外统一用“交往交流交融”；每站落到共同性，同时尊重差异性；民宗局审定时专项检查 |
| 森林火灾、山体滑塌 | 森林公园到达页与营地商品常驻防火提示；不售明火类商品；桩位避开滑塌点 |
| 引导游客去未建成或受保护的点位 | 望江亭建成前只讲故事；文物礼仪就近提示；点位开放状态由后台控制 |
| 人口等数据过时 | 县情数据集中配置，每年随县情概况更新 |
| 礼品被重复领取 | 实名、每证每年一次、动态领礼码、只能店员核销、核销必须联网 |
| 商城变成通用电商 | 商品必须关联站点与来源档案，否则不能上架 |
| 未授权素材 | 素材库标注授权状态，未授权不可选入内容卡 |
