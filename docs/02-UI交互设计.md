## 1. 视觉方向：「红土、水田、一条路」

### 1.1 为什么这样定

主题是“各族在同一片土地上”，所以视觉的主角是**土地本身**，而不是任何一个民族的服饰或图腾：

- **红土**：红河县山地的颜色，各族脚下同一种土。
- **水田**：冬春灌水季的梯田水面，也是森林公园那一沟水。
- **一条路**：长廊、马帮路、高速路，用一条细的虚线贯穿整个产品，代表“同路”。

民族纹样只在**获得授权后**以配饰边纹的形式出现，比例很小，四站的配饰并列、同等大小。

### 1.2 色彩

| 角色 | 名称 | 参考色值 | 用法 |
|---|---|---|---|
| 主色 | 红土赭 | `#A8452F` | 主按钮、已到站徽记、关键数字 |
| 辅色 | 水田青 | `#2F7A78` | 音频播放、答对、水系相关 |
| 点缀 | 竹黄 | `#D9A441` | 礼品、荣誉边框（少量使用） |
| 文字 | 墨 | `#22201C` | 正文 |
| 次级文字 | 灰岩 | `#6E6A63` | 说明、来源 |
| 底色 | 米纸 | `#F6F1E8` | 页面背景 |
| 卡片 | 素白 | `#FFFDF9` | 卡片 |
| 提醒 | 安全橙 | `#D9622B` | 只用于停车与安全提示 |

规则：一页之内主色不超过两处；不用渐变；不做红黄大面积“喜庆色”，避免“红头文件”感。

### 1.3 字体与排版

- 标题：思源宋体 SemiBold（带一点“书卷 + 地方志”的气质，但不是公文的黑体加粗）。
- 正文、数字：系统字体（苹方 / 思源黑体）。
- 字号：页面大标题 22，站名 20，卡片标题 17，正文 15（户外阅读，不小于 15），说明 13。
- 正文行高 1.6；户外强光下对比度不低于 4.5:1。

### 1.4 图形语言

| 元素 | 画法 |
|---|---|
| 长廊示意图 | 一条红土色细虚线（“路”），四个圆点站点挂在线上；线不是地图，不带比例尺和导航 |
| 站点徽记 | 圆形线描：路口=路牌，森林=水滴与树，古城=马铃铛，梯田=等高线。到过=线描；答懂=填色 |
| 底纹 | 梯田等高线，极淡（5% 透明度），只出现在页头 |
| 形象 | 中性旅人剪影，背着包；配饰挂在包和领口位置 |
| 图片 | 真实现场摄影，人物照片须经本人同意；不使用摆拍的“民族服装合影” |

### 1.5 户外可用性

- 主要按钮高度 52，单手拇指区（屏幕下 1/3）内。
- 音频控件大、可锁屏继续播。
- 所有页面在无网时都能打开（除支付和核销）。

## 2. 全局结构

```
底部标签栏： [ 长廊 ]   [ 一路好物 ]   [ 我的 ]
```

- 「长廊」是首页，任何时候点“打卡”都从这里开始。
- 店员模式不占标签位，从「我的」进入，且只对绑定账号可见。

## 3. 关键路径总览

```
到达            看内容            答题            得分                领礼               买走一件本地货
───────        ───────          ───────        ───────            ───────            ───────────
首页            现场页            答题页          记下这一站页          称号与礼品页         商品列表
「我已停好，     卡片 + 离线音频     3 题，答错       徽记点亮、同路分、      领礼码 → 店员扫码     → 商品详情（来源档案）
 打卡」          → 我看完了         先看讲解再得分     称号、礼品档位         → 已领取             → 寄回家 / 自提
 ↓ 取一次定位                                       ↓ 这一站的物产                                ↓ 农户收到带来源的订单
到达确认                                           加心愿单 / 买
```

可从任意一站开始；完成一站后，首页长廊上该站点亮，其余站保持“可去”状态，没有锁。

### 4.1 首页 · 长廊

**目的**：让刚停下车的人 3 秒内知道“点哪里打卡”，并看到这一路有什么、自己走到哪了。

```
┌─────────────────────────────────────┐
│ 红河同路                    [离线包 ✓] │  ← 宋体主名；右侧离线包状态
│ 各族同路走，好物一路带                    │
│ ┄┄┄┄ 梯田等高线淡底纹 ┄┄┄┄┄┄┄┄┄┄┄┄┄┄ │
├─────────────────────────────────────┤
│ ┌─────────────────────────────────┐ │
│ │ 到了一站？                        │ │
│ │ 先停好车，再点下面的按钮。           │ │
│ │ 我们只在你点按钮时取一次位置。        │ │
│ │ ┌─────────────────────────────┐ │ │
│ │ │      我已停好，打卡            │ │ │  ← 主按钮（红土赭）
│ │ └─────────────────────────────┘ │ │
│ │ 信号不好？ 扫现场桩码              │ │
│ └─────────────────────────────────┘ │
│                                     │
│ 这条长廊                 走过 1 / 4 站  │
│                                     │
│   ●───────○───────○───────○         │  ← 虚线“路”；●已到 ○未到
│  迤萨路口  森林公园   马帮古城  撒玛坝梯田  │
│  同住一县  共用      出门的人   同一片     │
│  同走一路  一沟水    和等的人   梯田       │
│                                     │
│  顺着走、倒着走都行。走一站就有礼。        │
│  只走两站？ 马帮古城 + 撒玛坝梯田 ›        │  ← 软推荐，不上锁
├─────────────────────────────────────┤
│ 你现在是「红河来客」  23 同路分           │
│ 已可领第一档礼 ›                        │  ← 进入称号与礼品页
├─────────────────────────────────────┤
│ 这一路你会遇到                    全部 ›  │
│ [梯田红米]  [竹编杯垫]  [尼苏刺绣]        │  ← 与站点相关，标注“在哪站遇到”
│  撒玛坝      马帮古城     马帮古城        │
├─────────────────────────────────────┤
│   长廊          一路好物          我的    │
└─────────────────────────────────────┘
```

**组件说明**

| 组件 | 说明 |
|---|---|
| 打卡卡片 | 永远在首屏最上方；文字先讲“停好车”，再讲“只取一次位置” |
| 长廊示意 | 四站等距排列，**不编号**；点站点进入该站预览（未到时只能看简介和物产，不能答题） |
| 称号条 | 只有完成至少一站后出现 |
| 这一路你会遇到 | 最多 3–4 件，按“已到站相关 > 将到站相关”排序；不是广告位 |
| 只走两站 | 一行文字链，点开是两站的简介与桩位说明；不改变其余两站的可达状态 |
| 怎么来 | 首页底部折叠区：自驾停车与充电信息；无车游客看「红达达」定制客运。只给文字信息，不导航 |

**交互**

1. 点「我已停好，打卡」→ 弹出到达确认底板（见 4.2.1）。
2. 首次进入且未下载离线包：页头显示「出发前下载四站离线包（约 60 MB）」，可只下载某一站。
3. 正在播放音频时，底部标签栏上方出现迷你播放条。

│                                     │

**定位结果状态**

| 结果 | 页面反馈 |
|---|---|
| 在某站范围内 | 直接进入该站现场页，顶部显示「已到达 · 撒玛坝观景台 · 10:42」 |
| 不在任何站范围内 | 「你离最近的打卡点还有一段路。到了访客停车场或观景台再点一次就好。」+ 各站桩位文字说明（不导航） |
| 单次定位显示在移动 | 「看起来车还在走。请停稳后再打卡。」不打卡 |
| 定位失败 / 无信号 | 「信号不好，可以扫现场桩码打卡。」→ 打开扫码 |
| 用户拒绝授权 | 「不授权位置也可以：扫现场桩码打卡。」 |

**交互**

- 卡片横向滑动，共 4 张；音频与卡片联动（音频播到哪段，卡片自动翻到哪张；用户手动翻卡不打断音频）。
- 「看完」判定：翻到最后一张，**或**音频播放超过 90%。满足任意一项即生成到访记录。
- 在「长街宴」卡片上就近出现礼仪提示条：「可以饮酒，也可以以茶代酒 · 拍人、拍院子、拍宴席前先问一声」。
- 在「乐作舞和多声部」卡片上，两项分为左右两栏，分别有标题，**视觉上明确是两件事**。乐作一栏写「在哈尼族、彝族群众中世代相传」。
- 最后一张卡片的末句是「共同性」句（如「各族世世代代一起守护的世界文化遗产」），排版上用正文字号，不做口号式大字。
- 右上角「现场礼仪」随时可看。

**各站现场页的差异**

| 站点 | 页头额外元素 | 说明 |
|---|---|---|
| 马帮侨乡森林公园 | 安全橙细横幅「高火险期园区内禁止一切野外用火」 | 高火险期由运营切换为加粗横幅；营地自提商品页同样显示 |

| 撒玛坝梯田结果页 | 「想多住几天？」入口 | 列出经认定的旅居示范点（如龙玛村） |

### 4.3 答题页

**目的**：用 3 道题确认“看懂了”；答错不惩罚，而是把正确的讲给你听。

```
┌─────────────────────────────────────┐
│ ‹ 撒玛坝梯田              第 3 / 3 题  │
│ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━   │
│                                     │
│ 乐作舞和哈尼多声部，                     │
│ 下面哪种说法对？                         │  ← 题干（宋体 19）
│                                     │
│ ┌─────────────────────────────────┐ │
│ │ A  是同一种表演的两个名字             │ │
│ └─────────────────────────────────┘ │
│ ┌─────────────────────────────────┐ │
│ │ B  乐作重舞，多声部重领唱与应和   ✓   │ │  ← 正确项（水田青描边）
│ └─────────────────────────────────┘ │
│ ┌─────────────────────────────────┐ │
│ │ C  都要穿全套民族服装才能看     ✕     │ │  ← 用户选错（灰岩，不用红色）
│ └─────────────────────────────────┘ │
│                                     │
│ ┌─────────────────────────────────┐ │
│ │ 正确的是 B                         │ │
│ │ 它们是两项不同的国家级非遗：一个看舞步，  │ │
│ │ 一个听一人领、众人和。被邀请时再一起跳乐作。│ │
│ │ 来自卡片「乐作舞和多声部」  回看 ›       │ │
│ │                        +3 同路分   │ │
│ └─────────────────────────────────┘ │
├─────────────────────────────────────┤
│ ┌─────────────────────────────────┐ │
│ │            继续                   │ │
│ └─────────────────────────────────┘ │
└─────────────────────────────────────┘
```

**交互与状态**

| 状态 | 表现 |
|---|---|
| 未作答 | 三个选项等高大卡片；无倒计时 |
| 答对 | 选中项变水田青，出现「答对了 +10」与一句讲解（讲解对答对的人也展示，短） |
| 答错 | 选中项灰显并标 ✕，正确项高亮；讲解卡展开，显示「+3 同路分」；**不用红色、不用“失败”字样** |
| 继续 | 讲解出现后按钮才可点，避免误触跳过 |
| 中途离开 | 进度保存，6 小时内回来继续 |

题目文案避免“考倒人”：选项长度相近，不设陷阱措辞。

## 6. 无障碍与边界情况

- 所有音频有文字稿；所有图片有替代文字。
- 系统字体放大到 1.3 倍时布局不溢出。
- 老人模式：首页只保留打卡按钮、长廊和礼品入口。
- 一个微信号对应一个登记证件；家庭出游每人各自领礼。
- 同一站跨年再来：重新计分，徽记显示“2026、2027”两个年份。
- 内容被下线：已看过的卡片在“我的”里显示“该内容正在更新”，分数保留。
- 族语排版：审定后出现族语时，普通话在前、字号更大，族语在后、字号小一级；音频先播普通话讲解。
