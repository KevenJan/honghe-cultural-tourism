# 通知、错误码文案与埋点

> 本文件三部分：①发给用户的通知（订阅消息、短信）；②接口错误码与前端提示文案；③埋点事件字典。文案是定稿，开发直接用；改文案改本文件。
> 文案风格：短句、说清下一步、不用「失败」「非法」「异常」这类词吓人；不用感叹号堆叠；不用「亲」。

---

## 1. 通知

### 1.1 游客 · 订阅消息

微信订阅消息需要用户每次授权（一次性订阅），所以**在用户刚做完相关操作时请求授权**，不在首页、不在打开时弹。模板要在微信公众平台按类目选用，下表「字段」以选到的模板为准，内容按下表填。

| 编号 | 触发 | 授权时机 | 字段与内容 | 点击进入 |
|---|---|---|---|---|
| N-U01 发货通知 | 合作社填单号 | 支付成功页 | 商品：{商品名}等{n}件；快递：{快递公司} {单号}；备注：{合作社}已发货 | P18 订单详情 |
| N-U02 可以取货 | 合作社点「已备好」 | 支付成功页 | 商品；自提点：{自提点}；时间：{开放时间}；备注：请出示订单里的自提码 | P18 |
| N-U03 自提提醒 | 自提日期后 3 天未取 | 同上（与 N-U02 同次授权，模板不同时需单独授权） | 备注：你的{商品}还在{自提点}，7 天内未取我们会联系你 | P18 |
| N-U04 售后进度 | 售后状态变化（同意 / 驳回 / 已退款 / 已补发） | 提交售后时 | 进度：{状态}；说明：{一句话} | P19 |
| N-U05 退款到账 | 微信退款成功 | 提交售后时 | 金额：{金额}；备注：原路退回，1–3 个工作日到账 | P18 |
| N-U06 反馈已处理 | 运营 / 审定员回复 | 提交反馈时 | 结果：{一句话结果} | P30 我的反馈 |
| N-U07 领取更正 | 撤销通过 | 出示领礼码时 | 备注：你的领取记录已更正，可以重新出示领礼码 | P23 |
| N-U08 到货提醒 | 售罄商品补货上架 | 点「到货告诉我」时 | 商品：{商品名}；备注：这批到了 | P14 |
| N-U09 订单将取消 | 待付款剩 5 分钟 | 不单独请求（如无授权则不发） | 备注：订单还有 5 分钟自动取消 | P18 |

**不发**：营销推送、降价提醒、「你还差 x 分」「快来打卡」之类催促消息。

## 2. 错误码与提示文案

**格式**：接口统一返回 `{code, message, data}`；`code` 为 0 表示成功，其他为下面的字符串码。前端**按 code 显示本表文案**，不直接展示 `message`（`message` 给开发排查用）。

### 2.1 通用

| code | 场景 | 前端表现 | 文案 |
|---|---|---|---|
| `UNAUTHORIZED` | 登录态失效 | 静默重新登录后重试一次；仍失败弹登录层 | 登录后才能记下你的到访和分数 |
| `FORBIDDEN` | 没权限（工作台） | 通用「没权限」页 | 这个页面只给工作人员使用 |
| `NOT_FOUND` | 对象不存在 | 通用空状态 | 没找到这个内容 |
| `OFFLINE_CONTENT` | 内容已下线 | 通用「内容已下线」 | 这部分内容正在更新 |
| `TOO_FREQUENT` | 频率限制 | Toast | 操作太快了，稍等一下 |
| `NETWORK` | 前端判断无网 / 超时 | 顶部条或按钮旁提示 | 网络不太好，再试一次 |
| `SERVER_ERROR` | 5xx | Toast | 出了点小问题，稍后再试 |
| `VERSION_TOO_OLD` | 小程序版本过低 | 弹窗，按钮「好的」触发 `wx.getUpdateManager` | 小程序有新版本，更新后再用 |

## 3. 埋点事件字典

### 3.1 公共字段

每个事件自动带：`user_id`（未登录为空）、`anon_id`（设备匿名 ID）、`session_id`、`ts`（毫秒）、`page`、`ch`（首次渠道）、`share_from`（如有）、`app_version`、`network`（wifi/4g/5g/none）、`offline`（是否离线记录，离线事件在同步时补报，带原始 `ts`）。

**不采集**：坐标、证件号、姓名、手机号、收货地址、问驮驮原文以外的输入内容。

### 3.2 事件

| 事件 | 触发 | 私有字段 | 用于指标 |
|---|---|---|---|
| `ev_app_launch` | 小程序启动 | `scene`（微信场景值） | 渠道 |
| `ev_page_view` | 每个页面 `onShow` | `ref_page` | 漏斗 |
| `ev_login` | 登录成功 | `trigger`（触发登录的操作） | 登录转化 |
| `ev_banner_click` | 首页大图点击 | `banner_id`、`index` | 大图效果 |
| `ev_entry_click` | 首页八格点击 | `entry` | 入口使用 |
| `ev_map_navigate` | 服务地图「用微信地图打开」 | `poi_id`、`poi_type` | — |
| `ev_checkin_submit` | 点「我到了」/「确认到达」 | `site`、`method`（gps/board）、`choice`（driver_stopped/passenger） | — |
| `ev_checkin_result` | 打卡返回 | `site`、`method`、`code`、`distance_100m`、`accuracy_band`、`duration_ms` | 到访、被拦次数、信号弱比例 |
| `ev_board_scan` | 扫立牌码 | `board_id`、`site`、`valid` | 立牌监控 |
| `ev_site_tab` | 站点页切页签 | `site`、`tab` | — |
| `ev_card_finish` | 看完导览最后一张卡 | `site` | 看完率 |

| `ev_quiz_answer` | 提交答案 | `site`、`question_id`、`correct` | 正确率（按题，用于发现难题和问题内容） |
| `ev_quiz_ack` | 点「我记住了」 | `question_id` | 讲解确认率 |
| `ev_site_complete` | 完成一站 | `site`、`score`、`minutes_since_checkin` | 完成率 |
| `ev_seed_open` | 点籽 | `site`、`ethnic`、`seed_state` | 籽关注度 |
| `ev_seed_known` | 籽变已认识 | `site`、`ethnic` | 认识籽数 |
| `ev_all_lit` | 四瓣全亮 | — | — |
| `ev_gift_code_show` | 出示领礼码 | `tier`、`traveler_count` | — |

| `ev_staff_redeem` | 店员确认发放 | `counter_id`、`tier`、`gift_id`、`downgraded` | 发放量 |
| `ev_staff_revoke` | 撤销申请 / 结果 | `counter_id`、`reason`、`approved` | — |
| `ev_product_view` | 商品详情 | `product_id`、`from_site` | 带货漏斗 |
| `ev_wish_add` | 加心愿单 | `product_id`、`from_site` | 心愿单数 |
| `ev_cart_add` | 加购物车 | `product_id`、`from_site` | — |
| `ev_order_submit` | 提交订单 | `order_id`、`amount`、`items`、`from_site`、`delivery` | 下单 |
| `ev_order_paid` | 支付成功（前端） | `order_id`、`amount` | 以服务端支付回调为准，此事件只用于漏斗 |
| `ev_rebuy` | 再买一次 | `order_id` | 复购 |
| `ev_ask_submit` | 问驮驮提问 | `hit`（qa/sensitive/miss）、`qa_id`、`from_chip` | 答上率 |
| `ev_ask_feedback` | 有用 / 没用 | `qa_id`、`useful` | 问答质量 |
