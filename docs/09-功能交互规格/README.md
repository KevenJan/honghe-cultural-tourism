## 1. 写法约定

### 1.1 编号

| 前缀 | 含义 | 例 |
|---|---|---|
| `M1`–`M8` | 游客端模块 | M2 到达打卡 |
| `F` | 功能点，`F模块-序号` | F2-3 定位比对 |
| `P` | 游客端页面 | P04 到达打卡页 |
| `S` | 店员端页面 | S01 店员工作台 |
| `H` | 合作社端页面 | H02 订单详情 |
| `A` | 运营后台页面，`A模块-序号` | A3-2 审定详情 |
| `L` | 闭环，见 08 号文件第 5 节 | L2 礼品闭环 |
| `E` | 错误码 / 提示，见 05 号文件 | E-CHK-03 |
| `ev_` | 埋点事件 | ev_checkin_submit |

### 1.2 每个功能点的固定结构

1. **闭环位置**：属于哪个闭环，起点是什么、终点是什么、出了意外回到哪一步。
2. **入口与参数**：从哪些地方进来，带什么参数。
3. **页面元素**：从上到下列出，标出哪些由后台配置。
4. **交互表**：用户做什么 → 界面怎么反馈 → 系统做什么（规则、接口）。
5. **状态**：加载中、空、出错、没网、未登录、没权限、内容下线，每种怎么显示。
6. **文案**：定稿文字，开发直接用，不要自己改写。改文案走后台或改本文件。
7. **验收要点**：测试按这几条测。

### 1.3 优先级

| 标记 | 含义 |
|---|---|
| 一期 | 上线必须有 |
| 一期·条件 | 一期做好功能，但要等甲方资料到位才打开（如一句红河话要等录音审定） |
| 二期 | 预留入口或数据字段，不做界面 |

## 3. 全局交互

### 3.1 登录与「登录记分」

**原则**：看内容、听音频、浏览商品、问驮驮都不用登录。只有要「留下记录」的操作才要登录：打卡、答题、领礼、下单、收藏、反馈。

| 步骤 | 界面 | 系统 |
|---|---|---|
| 1 | 用户点了需要登录的操作（例：「我到了」） | 检查本地是否有有效登录态 |
| 2 | 没有：底部弹层「登录后才能记下你的到访和分数」，下面两行小字「我们只用你的微信身份记分，不获取手机号」「登录即同意《用户协议》《隐私保护指引》」，按钮「登录记分」「先看看」 | — |
| 3 | 点「登录记分」 | 如未同意隐私协议，先走 3.2；然后 `wx.login` 取 code，换 openid，创建用户 |
| 4 | 弹层收起，**继续执行用户刚才点的那个操作**，不让用户再点一次 | 保留原操作的参数 |
| 5 | 点「先看看」 | 弹层收起，停在原页面，不再自动弹出，直到用户再次点需要登录的操作 |

- 不要求授权头像昵称。默认头像用中性旅人形象；昵称默认「红河同路人 + 4 位数字」，用户可在 P33 设置里改（用微信头像昵称填写能力）。
- 不获取手机号。需要电话的场景（收货、证件登记）由用户自己填写。
- 登录态 30 天；过期后静默重新登录，失败才弹登录层。

### 3.2 隐私协议

- 首次打开小程序不弹窗，不打断浏览。
- 第一次触发隐私相关接口（取位置、扫码、选地址、保存图片）前，用微信隐私协议弹窗（`wx.onNeedPrivacyAuthorization` + 自定义弹窗组件）。
- 自定义弹窗标题「使用前请看一下」，正文三行：
  - 取位置：只在你点「我到了」时取一次，用来确认你到了这一站。
  - 证件号：只用来保证每个证件每年领一次礼品，我们只保存加密后的结果。
  - 收货信息：只用来寄送你买的东西。
- 按钮「同意并继续」「不同意」。不同意时：本次操作取消，Toast「不同意也可以继续看内容」。

### 3.3 位置授权

- 只在 P04 点「我到了」时调用 `wx.getLocation({type:'gcj02', isHighAccuracy:true, highAccuracyExpireTime:8000})`。
- 用户拒绝过位置权限：再点「我到了」时弹层「需要位置权限才能确认到达」，按钮「去设置打开」（`wx.openSetting`）和「扫现场立牌码」。不反复弹系统授权框。

### 3.4 网络与离线

| 情况 | 全局表现 |
|---|---|
| 没网 | 页面顶部出现一条浅灰提示「现在没有网络，已下载的站点可以照常看、听、打卡」。网络恢复后提示条消失，并 Toast「已恢复网络，记录已同步」（如有待同步记录） |
| 弱网（请求超过 8 秒） | 按钮显示加载中；超时后提示「网络不太好，再试一次」，保留用户已填内容 |
| 必须联网的操作 | 领礼码、核销、支付、提交证件、提交反馈。没网时按钮置灰，旁边写「需要联网」 |

离线能做的事和同步规则见 [`04-规则与计算口径.md`](04-规则与计算口径.md) 第 6 节。

### 3.5 扫码进入（现场立牌码、分享）

| 来源 | 参数 | 落地页 |

### 3.7 通用状态

所有列表页、详情页都要做下面这几种状态，组件统一：

| 状态 | 表现 |
|---|---|
| 加载中 | 骨架屏，不用转圈占满全屏 |
| 空 | 吉祥物「思考」形象 + 一句话 + 一个下一步按钮（各页面文案见各功能点） |
| 出错 | 「没加载出来」+「再试一次」按钮 |
| 内容已下线 | 「这部分内容正在更新」+ 返回按钮；已得分数不受影响 |
| 没权限 | 「这个页面只给工作人员使用」+「回首页」 |

### 3.8 老人模式与字号

- P33 设置里可开「大字模式」：正文字号 +2，按钮高度 56，首页只保留「到达打卡」「四站」「领礼」「服务电话」四个大入口和防火公告。
- 系统字体放大到 1.3 倍时不能溢出、不能遮挡按钮。
- 所有图片有替代文字；所有音频有文字稿。

### 3.9 底部标签栏

自定义 tabBar，五项：首页、四站、问驮驮（中间凸起的吉祥物头像）、好物、我的。店员、合作社身份**不改变**标签栏，工作台入口在「我的」。
