# 现场立牌制作与安装规范

> 用途：四站「扫码打卡」立牌的设计、制作、安装、维护。立牌是山区没信号、定位不准时唯一的打卡方式（08 号验收标准第 1、7 条），必须可靠。
> 小程序码由运营后台 A4-2 生成，下载 PDF 直接交给制作单位。**不要自己用网上工具生成二维码**，后台生成的码带站点信息、可作废更换。

---

## 1. 每站数量与位置

| 站 | 数量 | 位置原则 |
|---|---|---|
| 迤萨路口 | 1–2 块 | 游客服务中心门口、停车场人行出口 |
| 森林公园 | 1–2 块 | 游客中心或主停车场步行区 |
| 马帮古城 | 2 块 | 古城入口服务点；不安装在文物本体上，不打孔、不粘贴在文物建筑墙面 |
| 撒玛坝梯田 | 2 块 | 观景台停车场人行区、木栈道入口 |

**必须**：

1. 装在**停好车之后步行能到**的地方，人站着扫码不挡车道。
2. 不装在匝道、主路边、弯道、临崖处、曾经滑塌的地段。
3. 不装在「拍照点」旁边，避免人群聚集在危险处。
4. 白天顺光、晚上有照明（或立牌自带反光）；扫码面朝人行方向。
5. 每块立牌安装后，由景区人员用手机实测：能扫出、进入的是对应站点。

位置确认后，在 `templates/站点信息.csv` 和后台 A4-2 填「位置说明」（例：观景台停车场人行出口左侧，距离公厕 20 米）。

## 2. 版面

| 项 | 规格 |
|---|---|
| 尺寸 | 600 × 900 mm（竖版）；空间不足可用 400 × 600 mm |
| 小程序码 | 边长 ≥ 250 mm（大版）/ ≥ 180 mm（小版）；四周留白 ≥ 码边长的 10% |
| 码的高度 | 码中心离地 1.2–1.4 米 |
| 文字 | 自上而下：「红河同路 · {站名}」；「扫码打卡」（最大字）；「请停好车后扫码 · 行驶中请勿操作」；码；「微信扫一扫 · 进入红河同路小程序」；底部「{县文旅局} · 服务电话 {电话}」 |
| 色彩 | 底色米白或浅色，码为深色（黑或深青）；**码不能反色、不能加花纹、不能改码中间的图标** |
| 字体 | 黑体 / 思源黑体；站名 ≥ 80 mm 字高 |
| 双语 | 「扫码打卡 / Scan to check in」 |
| 禁止 | 不放商业广告、不放其他二维码（避免扫错）、不放「拍照打卡点」字样 |

版面源文件由运营提供（AI / PDF），只替换站名和码。

## 3. 材质

| 部位 | 要求 |
|---|---|
| 牌面 | 3 mm 铝板 + 户外 UV 打印 + 哑光防紫外线覆膜（防反光，反光会扫不出） |
| 立柱 / 底座 | 镀锌钢管或与景区现有导视统一；抗风；底座混凝土预埋 |
| 古城 | 与古城导视风格统一，使用独立底座，不在文物上固定 |
| 防护 | 牌面四角圆角；边缘无毛刺 |

## 4. 验收

1. 3 台不同手机（安卓、苹果各至少 1 台），在 0.5 米、1 米、1.5 米距离扫码，均能识别并进入对应站点打卡页。
2. 弱光（傍晚）实测一次。
3. 拍照：远景 1 张（看周边环境）+ 近景 1 张（看码），发给运营在 A4-2 归档。

## 5. 维护

| 情况 | 处理 |
|---|---|
| 后台提醒「近 7 天无扫码」 | 景区 2 天内到现场检查：是否被遮挡、损坏、褪色 |
| 牌面损坏、褪色、被贴小广告 | 在后台作废旧码 → 生成新码 → 重新制作；旧牌拆除 |
| 发现被他人覆盖了别的二维码 | 立即拆除覆盖物，后台作废该码并生成新码，报运营 |
| 雨季、火险期 | 每月巡检一次 |

## 6. 时间

立牌须在上线前 3 周安装完毕，用于现场联调和店员培训。
