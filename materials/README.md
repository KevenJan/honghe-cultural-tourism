## 2. 格式要求

| 类型 | 要求 |
|---|---|
| 文字 | 填在模板里；一格一项，不要合并单元格；字数限制见模板第二行说明 |
| 图片 | JPG / PNG 原图，长边 ≥ 2000 像素；**实拍**，不要网图；不要加水印、文字、边框；人物正脸需有肖像授权 |
| 插画、纹样 | 矢量（AI / SVG / PDF）优先；位图 ≥ 3000 像素 |
| 音频 | WAV 或 MP3 320kbps；安静环境录制；单段 ≤ 3 分钟；必须附文字稿（普通话）；方言或族语附普通话译文 |
| 坐标 | 现场用手机地图（腾讯 / 高德）长按取点，记录经纬度（小数点后 6 位）并拍一张现场照片 |
| 资质文件 | 彩色扫描 PDF，每份文件单独一个 PDF，注明到期日 |

### 2.1 文件命名

`{站代号}_{类型}_{序号}_{简短说明}.{扩展名}`

- 站代号：`YS` 迤萨路口、`SL` 森林公园、`GC` 马帮古城、`SMB` 撒玛坝、`QX` 全县通用
- 类型：`IMG` 图片、`AUD` 音频、`PAT` 纹样、`DOC` 文件、`LIC` 授权书
- 例：`SMB_IMG_03_长街宴全景.jpg`、`GC_AUD_01_马帮与侨乡.mp3`、`QX_LIC_05_某某录音授权.pdf`

模板里的「文件名」列填这个名字，用来对应。

### 2.2 怎么交

1. 按站建文件夹：`YS/`、`SL/`、`GC/`、`SMB/`、`QX/`，每个下面放 `图片/`、`音频/`、`授权/`。
2. 填好的模板 CSV（或 Excel）放在最外层。
3. 打包通过县文旅局指定的网盘或硬盘交给运营主体；**不要通过微信群传原图和证件扫描件**。
4. 运营收到后 3 个工作日内回一份《资料核对单》，写明缺什么、哪些不合格。

## 4. 内容写作要点（发给起草人）

1. **每张卡落到「共同」**：同一条路、同一沟水、同一条街、同一片田上，各族一起做了什么。不要罗列各族差异，不要猎奇。
2. **短**：标题 ≤ 14 字，正文 ≤ 120 字，游客站着 30 秒能看完。
3. **有出处**：非遗级别写名录批次和编号；数字写来自县情数据哪一项。
4. **族语以普通话为主**：需要出现的族语词，用普通话写出意思；不写族语文字。
5. **题目的讲解必须能在内容卡里找到原话**，不要出卡片里没有的知识点。
6. 民族、宗教相关的表述先过民宗局，古城相关先过文物部门。
