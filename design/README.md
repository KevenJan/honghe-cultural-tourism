# 红河同路 · 游客端设计稿

给前端还原用的高保真画板。页面编号、路由、文案与 [`docs/09-功能交互规格/`](../docs/09-功能交互规格/README.md) 一致。颜色和字号与 [`assets/design-tokens.json`](../assets/design-tokens.json) 一致。

## 打开

用浏览器打开 [`index.html`](index.html)。点画板进入单页：红色编号是标注，右侧是尺寸、交互和状态说明，左右方向键翻页。[`components.html`](components.html) 是颜色、字号、按钮和通用状态。

部署时把 `design/` 和它引用的 `assets/`、`presentation/js/`（石榴坐标和示意数据）放在同一级目录。

## 范围

游客端 34 个页面（P01–P34）加上全局组件，每个页面含默认态和规格里点名的状态、弹层。店员端、合作社端、运营后台不在这批。

| 批次 | 内容 |
|---|---|
| 全局 | 登录、隐私、位置权限、没网、空、出错、下线、没权限 |
| 第 1 批 | 首页到问驮驮、我的、称号与礼品、领礼码、证件 |
| 第 2 批 | 一路好物的浏览、下单、支付、订单、售后、评价、心愿单 |
| 第 3 批 | 同路册、离线包、礼仪、反馈、电话、关于、设置 |

P34 研学团队是二期，一期只在首页格子上提示。P11 一句红河话是一期·条件，等录音审定再打开。

## 改稿

- 画面写在 `js/boards-*.js`，用 `js/kit.js` 的片段拼。样式在 `css/`，页面新增样式加自己的前缀，不改 `css/ui.css` 里已有类的含义。
- 改了标题用字后运行 `python3 tools/build_design_font.py`，否则新字会退回系统宋体。
- 商品、礼品、人名、电话、内容文字都是示意。分数示例按规则凑：答对 10、记住讲解 3，单站满分 30。

## 和规格冲突时

以 `docs/09-功能交互规格/` 为准，回改画板。下面几处规格没写死，画板先按这个处理，确认后改：

- 订单列表的页签用：全部、待付款、等发货、已发货、自提、售后。
- 两种配送方式一起结算时，确认页顶部用分段切换，合计一次支付。
- 自提订单的分组标题写「由{合作社}备货」。
- 从迤萨路口进商品详情，只留「加心愿单」，不放单独的心形按钮。
- 一个微信号只登记本人一个证件，不画「替家人领取」的选择层。
- 审定行示例用「内容经县文化馆、民宗局审定 · 2026-09」，正式以审定稿的单位名单为准。
